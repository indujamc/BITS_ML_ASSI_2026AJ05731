# Dry Bean Classification – Machine Learning Assignment 2

## a. Problem statement
The objective is to build and compare five supervised classification algorithms that predict the variety of a dry bean from 16 geometric measurements extracted from bean images. The models are evaluated on the same held-out test set using Accuracy, macro one-vs-rest AUC, macro Precision, macro Recall, macro F1 and Matthews Correlation Coefficient (MCC).

## b. Dataset description
**Source:** UCI Machine Learning Repository – Dry Bean dataset  
**Official page:** https://archive.ics.uci.edu/dataset/602/dry+bean+dataset  
**DOI:** https://doi.org/10.24432/C50S4B

The UCI record reports 13,611 instances, 16 numerical features and seven target classes: Seker, Barbunya, Bombay, Cali, Dermason, Horoz and Sira. The features describe size and shape properties such as area, perimeter, axis lengths, eccentricity, convex area, equivalent diameter, extent, solidity, roundness, compactness and shape factors. The dataset is licensed under CC BY 4.0. Cite the UCI dataset when reusing it.

## d. Models used and evaluation

### Experimental procedure
1. The data are split into 80% training and 20% test data using `random_state=42` and stratification.
2. Missing numerical values, if any, are median-imputed inside each model pipeline.
3. StandardScaler is applied inside the pipelines for Logistic Regression, KNN, Gaussian Naive Bayes and SVM. Decision Tree is not scaled.
4. All five models are fitted only on the training split.
5. All metrics are calculated on the same untouched test split. AUC is macro one-vs-rest multiclass AUC; Precision, Recall and F1 are macro-averaged.

## Running the project locally

```bash
# 1. Create and activate a virtual environment (recommended)
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Download data from UCI
python download_data.py

# 4. Train and evaluate the five models
python train.py

# 5. Launch the application
streamlit run app.py
```

The training script creates the held-out `test_data.csv`, saved model pipelines and output reports. Commit these generated artifacts to GitHub before deploying the Streamlit app. The app accepts a labelled test CSV containing the 16 feature columns and `Class`; it loads the saved models and does not retrain.
