# Dry Bean Classification – Machine Learning Assignment 2

## a. Problem statement
The objective is to build and compare five supervised classification algorithms that predict the variety of a dry bean from 16 geometric measurements extracted from bean images. The models are evaluated on the same held-out test set using Accuracy, macro one-vs-rest AUC, macro Precision, macro Recall, macro F1 and Matthews Correlation Coefficient (MCC).

## b. Dataset description
**Source:** UCI Machine Learning Repository – Dry Bean dataset  
**Official page:** https://archive.ics.uci.edu/dataset/602/dry+bean+dataset  
**DOI:** https://doi.org/10.24432/C50S4B

The UCI record reports 13,611 instances, 16 numerical features and seven target classes: Seker, Barbunya, Bombay, Cali, Dermason, Horoz and Sira. The features describe size and shape properties such as area, perimeter, axis lengths, eccentricity, convex area, equivalent diameter, extent, solidity, roundness, compactness and shape factors. The dataset is licensed under CC BY 4.0. Cite the UCI dataset when reusing it.

## d. Models used and evaluation

### Experimental procedure
1. The data are split into 80% training and 20% test data using `random_state=42` and stratification.
2. Missing numerical values, if any, are median-imputed inside each model pipeline.
3. StandardScaler is applied inside the pipelines for Logistic Regression, KNN, Gaussian Naive Bayes and SVM. Decision Tree is not scaled.
4. All five models are fitted only on the training split.
5. All metrics are calculated on the same untouched test split. AUC is macro one-vs-rest multiclass AUC; Precision, Recall and F1 are macro-averaged.

### Observations on model performance

| Model                  | Key Strengths                                                                             | Key Limitations                                                                    | Overall Observation                                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Logistic Regression    | High AUC (0.9947) and macro F1 (0.9303); performs well on BOMBAY and HOROZ.               | Lower SIRA F1 (0.86); linear boundaries may not capture all complex relationships. | Strong baseline; linear classification is effective but has limitations with overlapping classes.          |
| Decision Tree          | Captures nonlinear relationships and feature interactions; perfect BOMBAY classification. | Lowest macro F1 (0.9069) and AUC (0.9522); SIRA recall is 0.80.                    | Weaker test performance; overfitting cannot be confirmed without comparing training and test scores.       |
| K-Nearest Neighbors    | Good macro F1 (0.9292); performs well with standardized features.                         | Lower BARBUNYA recall (0.87) and SIRA precision (0.84).                            | Distance-based classification works well, but performance depends on feature scaling and class separation. |
| Gaussian Naive Bayes   | High AUC (0.9916); perfect BOMBAY classification.                                         | Macro F1 of 0.9091; lower BARBUNYA recall (0.80) and SIRA precision (0.81).        | Conditional-independence assumptions may limit its ability to model relationships among features.          |
| Support Vector Machine | Highest accuracy (92.54%), macro F1 (0.9372), AUC (0.9949), and MCC (0.9100).             | SIRA has the lowest class-wise F1 (0.87).                                          | Best overall performer; the RBF kernel effectively captures nonlinear class boundaries.                    |

Overall Winner: Support Vector Machine (SVM)

SVM achieved the highest test macro F1-score (0.9372), making it the best model for balanced classification across the seven bean classes. Its high AUC and MCC further demonstrate strong classification performance. Logistic Regression and KNN were also competitive, while Decision Tree and Gaussian Naive Bayes showed comparatively lower macro F1-scores.
